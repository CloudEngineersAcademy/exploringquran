## STEP 1️⃣: Create Gmail Account

### Instructions:

1. **Open Gmail Signup Page**
   - Go to: [accounts.google.com/signup](https://accounts.google.com/signup)
   - Or search "Create Gmail Account"

2. **Fill in Details**
   ```
   First name: Exploring
   Last name: Quran
   Username: ExploringQuran
   Password: [Create a strong password - save it securely!]
   ```

   ⚠️ **Important**: 
   - Write down your password in a safe place
   - Use a password manager (LastPass, 1Password, Bitwarden)
   - Example secure password: `Quran@2026!Guidance#Islamic`

3. **Add Phone Number**
   - Google requires phone verification
   - Enter your mobile number
   - You'll receive a 6-digit code via SMS
   - Enter the code to verify

4. **Add Recovery Email (Optional but Recommended)**
   - Add your personal email for account recovery
   - This helps if you forget your password

5. **Birth Date & Gender**
   - Enter any valid birth date
   - Select gender preference

6. **Accept Terms & Conditions**
   - Review Google's Privacy Policy
   - Click "I agree"

7. **✅ Done!** Your email is: **ExploringQuran@gmail.com**

### Post-Setup:
- ✅ Check inbox - you should see welcome emails
- ✅ Set up Gmail app on your phone (optional)
- ✅ Enable 2-Factor Authentication (Settings → Security)

## STEP 2️⃣: Create GitHub Account

### Instructions:

1. **Open GitHub Signup Page**
   - Go to: [github.com/signup](https://github.com/signup)

2. **Enter Email**
   ```
   Email: ExploringQuran@gmail.com
   ```
   - Click "Continue"

3. **Create Password**
   - Use a strong password (can be same as Gmail or different)
   - Must be at least 8 characters
   - Include numbers and special characters
   - Click "Continue"

4. **Choose Username**
   ```
   Username: ExploringQuran
   ```
   
   ⚠️ **Note**: Username cannot have spaces
    - If taken, try: `ExploringQuran2`, `QuranExplorer`, etc.
   - Click "Continue"

5. **Email Preferences**
   - Uncheck "Email me..." (or keep it checked if you want updates)
   - Click "Continue"

6. **Verify You're Human**
   - Complete the CAPTCHA puzzle
   - Click "Create account"

7. **Verify Email**
   - Check ExploringQuran@gmail.com
   - Look for email from GitHub
   - Click the verification link
   - Or enter the 8-digit code shown

8. **Personalization (Optional)**
   - "How many people are on your team?" → Just me
   - "What do you want to use GitHub for?" → Learning to code / Other
   - Click "Continue" or "Skip"

9. **Choose Plan**
   - Select **"Free"** plan
   - You get unlimited public repositories (perfect for GitHub Pages)

10. **✅ Done!** Your GitHub account is ready!

### Post-Setup:
- ✅ Set profile picture (use Islamic symbol or Arabic calligraphy)
- ✅ Add bio: "Islamic educational platform - Exploring the Quran for guidance"

## STEP 4️⃣: Enable GitHub Pages

### Instructions:

1. **Go to Repository Settings**
   - On your repository page, click "Settings" (top right)

2. **Navigate to Pages**
   - Left sidebar → Click "Pages"

3. **Configure Source**
   ```
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
   ```

4. **Click "Save"**

5. **Wait 1-2 minutes**
   - GitHub will build your site
   - Refresh the page

6. **Get Your Website URL**
   ```
   🌐 https://ExploringQuran.github.io/ExploringQuran/
   ```

7. **✅ Done!** GitHub Pages is enabled!

## STEP 5️⃣: Upload Website Files

### Option A: Using Git (Recommended)

Open PowerShell and run:

```powershell

cd "C:\Users\AmirShahzad\.azure\Users-and-Groups-Administration\QuranExplorer"

# Initialize Git (if not already done)
git init

# Add all files
git add .

# Commit files
git commit -m "Initial commit - Exploring Quran website"

# Set branch to main
git branch -M main

# Connect to your GitHub repository
git remote add origin https://github.com/ExploringQuran/ExploringQuran.git

# Push to GitHub
git push -u origin main
```

**Authenticate when prompted:**
- Username: ExploringQuran
- Password: Use a **Personal Access Token** (not your password)

**To create Personal Access Token:**
1. GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
2. Generate new token → Select "repo" scope → Generate
3. Copy the token (you won't see it again!)
4. Use this token as your password when pushing

### Option B: Upload via Web (Easier for beginners)

1. **Go to your repository**
   - https://github.com/ExploringQuran/ExploringQuran

2. **Click "Add file" → "Upload files"**

3. **Drag and drop your files**

     - index.html
     - mosques.html
     - README.md
     - All other files

4. **Commit changes**
   ```
   Commit message: Add website files
   ```
   - Click "Commit changes"

5. **✅ Done!** Files are uploaded!

## 🆘 Troubleshooting

### Issue: Gmail username already taken
**Solution:** Try variations:
- ExploringQuran2
- TheExploringQuran
- ExploringQuranOfficial
- ExploringQuran2026

### Issue: GitHub username already taken
**Solution:** Try:
- ExploringQuran2
- QuranExplorer
- ExploringQuranOfficial

### Issue: Can't push to GitHub
**Solution:**
1. Make sure you're using Personal Access Token, not password
2. Check remote URL: `git remote -v`
3. If wrong, update: `git remote set-url origin https://github.com/USERNAME/REPO.git`

### Issue: Website shows 404
**Solution:**
1. Wait 5 minutes after enabling GitHub Pages
2. Check repository is public
3. Verify branch is set to "main"
4. Check Settings → Pages for any errors

### Issue: YouTube channel not appearing
**Solution:**
1. Wait 24 hours for channel to be fully set up
2. Make sure you verified your email
3. Check YouTube Studio dashboard
